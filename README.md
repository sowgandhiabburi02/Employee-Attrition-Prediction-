# Employee-Attrition-Prediction-
A Machine Learning project that predicts whether an employee is likely to leave the company using HR analytics data. Built 6 models; Random Forest achieved 88% accuracy, 85% precision. Balanced dataset using SMOTE; handled 20+ features via encoding. Identified key attrition factors (e.g., salary, job role) to aid HR decisions.
🔍 Overview
This project analyzes employee-related factors such as age, salary, experience, and work-life balance to identify the main reasons for attrition. It uses algorithms like Logistic Regression and Random Forest to predict employee turnover.
